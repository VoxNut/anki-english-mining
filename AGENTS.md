# Project workflow

This is the public English Mining note-type repository. The owner has authorized committing and pushing completed changes without asking again. Run the checks appropriate to each change, commit the finished work, and push to the configured origin.

Keep all existing field names and review data intact. Preserve saved user settings when updating live Anki. Keep English media, preset files, storage keys, and CSS variables separate from Japanese Senren.

Never commit collection databases, backups, real note exports, account credentials, or private test snapshots. Tests use synthetic fixtures and mocked AnkiConnect writes.

Keep the public preset file limited to a generic Default preset; do not replace it with a user's personal named presets or deck links.
